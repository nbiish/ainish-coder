# Plan: retire the RAG vocabulary and the embedding era outright

## 1. Problem

The embedding model and the vector store were deleted on 2026-11-12, but the repository still reads
as if they exist: a `rag/` package, a `bin/ainish-rag` launcher, `--embed-config`, nine retired
subcommand aliases, a `docs/rag-context-system-plan.md`, an ignored `.agents/rag/lancedb/` directory,
and roughly 126 embedding-flavoured mentions inside `src/rag/rag.py` alone. An agent reading this repo
cannot tell what is live from what is a tombstone, which is the exact confusion the context system is
supposed to prevent. Modern harnesses carry ~1M tokens, so the corpus (340,322 tokens, measured) no
longer needs a vector index to be reachable — the retrieval question is what to PUT in a 4K prime, not
how to find it.

## 2. Anchor Facts

- Total corpus the graph indexes: **340,322 tokens across 172 files** — measured by summing
  `_graph_sources` output on `6ec427a`.
- `bin/ainish-coder:65` sources `src/embed_config.sh`; `:416` dispatches `--embed-config`; `src/help.sh`
  documents six `--embed-config` forms — grep.
- `src/rag/rag.py:8307` defines a `_RETIRED` dict of nine aliases (`serve`, `stop`, `index`, `query`,
  `rerank`, `bench`, `monitor`, `embed-provider`, `service`) that still register argparse subparsers.
- Python has **verb parity** with the Rust crate: `wiki`, `route`, `decide`, `gate`, `statusline`,
  `orient`, `cleanup`, `audit` all exist in both — grep of each name.
- The Rust crate (`src/rag/`) is the **only** implementation that writes `.agents/wiki/ledger.md` and
  its ML-DSA-65 envelope — `src/rag/src/main.rs:739-758`.
- `bin/pqc-secrets vault sign <FILE>` exists and writes a detached `<bundle>.sig` — `--help`, and
  `src/pqc-secrets/src/issue.rs:21`.
- CI never audits the crate: `.github/workflows/security.yml:44` audits only `src/cmd-tracker` and
  `src/pqc-secrets`.
- `.agents/audit/lockfile-manifest.json` **pins `src/rag/Cargo.lock`** by sha256.
- `src/deploy_rules_sync.sh:116-123` resolves a compiled `ainish-rag` binary for ML-DSA-65
  signing/verification of deployed rules.
- 183 tracked files mention `ainish-rag`; ~140 are immutable history and 15 are signed receipts.
- `ainish-rag wiki -n probe` regenerates all six vault pages from the stale binary, overwriting
  hand-corrected pages — reproduced on 2026-11-19 and reverted from git.

## 3. Plan

### Goals

- No live code, doc, or help text describes an embedding model, vector store, or `rag` tooling.
- One Python context engine at a path that says what it is; no Rust crate, no stale binary.
- `wiki/ledger.md` signing still works, through `pqc-secrets` rather than a compiled renderer.
- Immutable history and signed receipts are untouched, and the contract keeps its 160-line gate.

### Non-goals

- Rewriting `.agents/{comms,plans,tasks,memories,suggestions}` or `research/` records: renaming a
  record falsifies it.
- Changing how retrieval ranks. The graph stays as a relevance ranker; 340K tokens fitting in a 1M
  window does not make an unfiltered dump fit a 4K prime.
- Touching `.scrolls/`: separate concern, tracked, and unrelated to embedding.

### Constraints and invariants

- `AGENTS.md` stays at 160 lines.
- `scripts/test-pqc-dist.sh` must pass at or above its current 382 assertions, updated where an
  assertion described the removed surface.
- Signed artifacts (`.agents/audit/`, `.agents/canonical/*.sig`) are never hand-edited.
- The `contract-history` hash chain stays verifiable.

### Proposed architecture

```
before                                  after
ainish-coder --context "<input>"        ainish-coder --context "<input>"     (unchanged)
  └─ bin/ainish-rag → src/rag/rag.py      └─ bin/ainish-context → src/context/engine.py
       + tries compiled Rust binary             (no Rust, no fallback)
  └─ wiki refresh refuses (signed ledger)  └─ refresh works; ledger signed via pqc-secrets
```

### Interfaces and data

- `bin/ainish-context` — new launcher, same contract as `bin/ainish-rag` minus the native-binary
  dispatch. `bin/ainish-rag` becomes a shim that forwards and prints one deprecation line.
- `src/context/` — the engine, moved from `src/rag/`; `rag.py` → `engine.py`.
- `src/embed_config.sh` — deleted, with its `--embed-config` dispatcher and help block.
- `context_harness.sign_ledger(path) -> {ok, sig, reason}` — uses `pqc-secrets vault sign`.
- `provenance.engine` — `ainish-coder/context-engine` (was `ainish-rag/python`).

### Files and symbols

- `bin/ainish-coder` — source of `embed_config.sh`, the `--embed-config` case, the `--rag` case, and
  every `AINISH_BIN_DIR/ainish-rag` call.
- `bin/ainish-rag`, `bin/ainish-rag.cmd` — become forwarding shims; `bin/ainish-context{,.cmd}` added.
- `src/rag/{rag.py,context_harness.py}` → `src/context/{engine.py,context_harness.py}`.
- `src/rag/src/`, `src/rag/Cargo.{toml,lock}`, `src/rag/target/` — deleted.
- `src/rag/tests/` → `src/context/tests/`.
- `src/embed_config.sh`, `docs/rag-context-system-plan.md` — deleted.
- `src/help.sh`, `llms.txt`, `README.md`, `CONTRIBUTING.md` — live prose rewritten.
- `.agents/audit/lockfile-manifest.json` — the `src/rag/Cargo.lock` entry removed and re-signed.
- `scripts/test-pqc-dist.sh` — assertions repointed; new ones for the retirement.

### Alternatives considered

| Alternative | Why rejected |
|---|---|
| Keep the Rust crate as a stripped vault renderer | Operator chose deletion; Python has full verb parity and the crate is what silently overwrites the wiki |
| Delete the crate without porting ledger signing | Would silently drop signed governance history — a downgrade that looks like success |
| Rename history files that mention `ainish-rag` | Falsifies the record; the contract forbids it |
| Rip out the graph now that context is large | The prime is 4K tokens against a 340K corpus; ranking is still the job |

### Risks and mitigations

| Risk | Mitigation |
|---|---|
| Ledger signing breaks, losing signed governance history | Port to `pqc-secrets vault sign` and verify with `ainish-rag audit contract --verify-history` before deleting the crate |
| A deploy target still calls `ainish-rag` | The shim forwards; nothing breaks, and it names the new command |
| The lockfile manifest fails its integrity gate | Regenerate the manifest and re-sign; never hand-edit the entry |
| Stale binary in `src/rag/target/` overwrites the wiki again | The directory is deleted in the same commit that removes the crate |
| An assertion silently stops testing anything | Repoint each one to the new surface rather than deleting it |

## 4. Clarifications

### 4.1 The Rust crate

- **Question:** `src/rag/` is the only thing that signs `wiki/ledger.md`, but Python has full verb parity and `pqc-secrets vault sign` can sign files. What happens to it?
- **Options:** 1. (Recommended) Delete `src/rag/src` + `Cargo.toml`; port signing to `pqc-secrets`; keep the Python engine; 2. Strip only the embedding code and rebuild as a pure vault renderer; 3. Leave it alone.
- **Selected:** 1 — delete.
- **Trade-off accepted:** The Obsidian vault renderer becomes the Python one, which is less featureful (no signed ledger splice by itself), so signing moves to a separate explicit step.
- **asked:** operator

### 4.2 Retrieval shape

- **Question:** With 1M-context agents and a 340K-token corpus, does retrieval stay a graph ranker?
- **Options:** 1. (Recommended) Keep the graph as a relevance ranker; 2. Replace it with whole-corpus loading; 3. Add a `--full-corpus` mode.
- **Selected:** 1 — keep the graph.
- **Trade-off accepted:** The graph's tuning surface stays, which is more machinery than a pure dump — but the prime is 4K tokens, so something must choose.
- **asked:** operator
