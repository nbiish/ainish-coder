## Objective
Harden the canonical AGENTS.md symlink deployment, write protection, and git pre-commit hook defenses across Linux and macOS (Darwin) environments alongside Windows.

## Changes Completed
1. `src/agents_protection.sh`:
   - Added `_is_darwin()` and `_is_linux()` OS detection alongside `_is_windows_env()`.
   - `lock_agents_contract`:
     - On macOS: Applies `chmod 444`, followed by `chflags uchg` user immutable flag (making the file kernel-immutable against modification or removal even by owner).
     - On Linux: Applies `chmod 444` / `chmod a-w` and falls back to `chattr +i` if permitted.
     - On Windows: Applies `attrib +R` and `chmod 444`.
   - `unlock_agents_contract`:
     - On macOS: Clears `chflags nouchg` first so permissions can be modified, then restores `chmod 644`.
     - On Linux: Clears `chattr -i`, restores `chmod 644`.
     - On Windows: Clears `attrib -R`, restores `chmod 644`.
   - `is_agents_contract_locked`: Checks write permissions, `ls -lO` (`uchg`), `lsattr` (`i`), and `attrib` (`R`).
   - `_calc_sha256`: Implemented resilient multi-tier fallback: `sha256sum` -> `shasum -a 256` -> `openssl dgst -sha256` -> `python3` -> `powershell.exe` -> `cksum`.
   - `install_agents_pre_commit_guard`:
     - Replaced raw terminal escapes with POSIX-standard `printf` (compatible with Ubuntu `dash`, macOS `zsh`/`bash`, BSD `sh`).
     - Prepends guard logic directly after hook shebang (`#!/bin/sh`) so it reliably executes before other scripts or intermediate `exit 0` statements.
     - Sets executable permissions via `chmod 755`.
2. `src/deploy_agents.sh`:
   - Added self-contained `SRC_DIR` fallback safe against `set -u` execution.
   - Used `pwd -P` to resolve absolute source paths, resolving intermediate physical links portably.
   - Added `unlock_agents_contract "$dest"` before removing or backing up destination files on macOS/Linux.
   - Used `ln -sfn` / `ln -sf` for portable POSIX linking.
3. `src/deploy_local_security.sh`:
   - Ensured `install_ainish_git_hooks` cooperates with `install_agents_pre_commit_guard`, keeping both local secret sanitization and canonical AGENTS.md protection active.
4. `scripts/setup-hooks.sh`:
   - Replaced GNU-only `xargs -0 -r` with a POSIX loop that runs without errors on macOS BSD `xargs`.
5. `scripts/hooks/agents-md-sync.sh`:
   - Switched to `[ "$dest" -ef "$AGENTS_SOURCE" ]` for reliable device/inode comparison.
   - Unlocks immutable flags before replacing stale links.
6. `bin/ainish-coder`:
   - Added editor fallback for `vi` and macOS GUI `open -W -t` in `--edit-rules`.
7. Verification:
   - Automated 7-part test suite passed under native Linux bash: OS detection, SHA256 calculation, lock/unlock, canonical snapshot & restore, symlink live propagation, downstream git pre-commit rejection, and local-security co-existence.
   - Zero-Trust and PQC security gate (`security_gate.py`) passed cleanly.
