## Bugs found while doing it

1. **`audit verify` was a fail-open gate.** It checked that a `.sig` file existed, so a manifest
   rewritten after signing still read PASS. Reproduced: the committed envelope was from 2026-10-29
   and named different bytes. It now compares digests and fails with both.
2. **`audit sign` silently did nothing.** It wrote `lockfile-manifest.json.sig` while every reader
   looks for `lockfile-manifest.sig`, and returned success.
3. **`audit lock --update` from a worktree wrote the MAIN checkout's manifest**, because audit verbs
   resolved the canonical root. Receipts describe *this* checkout, so they now use the worktree root;
   shared caches keep the canonical one.
4. **The Python keygen wrote a sha256 hash where a public key belongs**, so it produced a trust anchor
   nothing could verify against.
5. **`--rules` manifest signing was broken by the deletion**, not by this change: it had always
   required a compiled binary, and that binary is gone.
