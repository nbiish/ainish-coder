## Objective

Operator asks: (1) when the PQC store holds a key **and** variables for an embedding API from
OpenRouter or ZenMux, ainish-rag must use that API for RAG instead of always relying on the local
model; (2) the system must release system memory and never leave the model resident outside its
usage. `ainish-coder --rules` must configure this too.

## What shipped

1. **Provider resolution (`src/rag/src/provider.rs`, new).** Operator intent (env
   `AINISH_EMBED_PROVIDER` or persisted `.agents/rag/embed-provider.json`) wins; otherwise the
   resolver checks the environment, then the PQC store (`pqc-secrets export --json`, decrypted in
   memory only). Accepted names include `AINISH_EMBED_API_KEY`, `OPENROUTER_*`, `ZENMUX_*`, and the
   consumer-prefixed `LOCALROUTER_OPENROUTER_API_KEY` / `LOCALROUTER_ZENMUX_API_KEY` that the store
   actually holds. Catalog defaults: OpenRouter `https://openrouter.ai/api/v1`, ZenMux
   `https://zenmux.ai/api/v1`, model `openai/text-embedding-3-small` (1536-d, truncated to the
   store's 768). Keys are never persisted or logged — only `key_source` provenance.
2. **Commands.** `ainish-rag embed-provider [--json|--write|--clear|--provider local|api|auto|openrouter|zenmux]`;
   `ainish-coder --embed-config --detect [--json] [--write]`; `--embed-config --provider openrouter|zenmux|auto`;
   `--embed-config --clear`; `--status` now reports the detected posture as well.
3. **`--rules`.** `deploy_rules_bundle` runs `deploy_embed_provider_detect`, which invokes the engine
   in the target repo and persists only non-secret config when a real remote credential is found
   (nothing is written otherwise, so a later-added key is still detected).
4. **Fail closed.** An auto-detected provider is probed once at command start (POST /embeddings,
   8 s, `AINISH_EMBED_PROBE=0` disables); an invalid probe aborts with remediation instead of
   silently indexing with a broken provider. An explicit incomplete `provider=api` intent resolves
   to `invalid` and refuses to run.
5. **Memory lifecycle.** `LlamaServer::ephemeral_guard` + `ensure_running` mark only servers this
   process spawned; a `Drop` guard kills the process tree on every exit path (including `?` errors).
   `--keep-server` / `AINISH_RAG_KEEP_SERVER=1` opts out; `serve` and `service status --warm` stay
   resident by design. Switching to API reclaims a resident local model, and `stop --purge` removes
   `session.psk*`. Python parity: atexit + SIGTERM teardown.
6. **Correctness guard for the switch.** Remote vectors are truncated + renormalized to 768; a
   successful index writes `.agents/rag/index-fingerprint.json`; any later mismatch warns that
   `ainish-rag index --rebuild` is required (new `--rebuild` flag drops the store first).
   Remote batch sizing starts at 32 and scales to 128 (loopback keeps 16→64).
