## What was wrong before

The decision layer targeted `typesafe/jev-1.13` and an older response shape. Live probing proved two defects: the Decisions API now **requires `criteria`** on every noul/choice/score question (requests returned `400 invalid_type`), and answers arrive under `answers` with typed values (`noul` float, `choice`, continuous `score`) — the code read `decisions`/`value`/`probability`, so it silently produced defaults even on success. Key resolution also only checked `OPENROUTER_API_KEY`/`ROUTER_API_KEY`, while the PQC store holds `LOCALROUTER_OPENROUTER_API_KEY`, so the whole layer fell back to heuristics.

## What shipped

1. **Live contract (`src/rag/src/decision.rs`, `src/rag/rag.py`)** — `typesafe/jev-1.14` (dated build reported in `source`), automatic `jev-1.13` retry when an id is retired, mandatory `criteria` on all question types, typed parser for `answers` with legacy tolerance, UTF-8-safe truncation.
2. **Bundled rerank** — one request per query for up to 12 candidates: direct-answer noul, symbol-grounding noul, 1–5 utility score, artefact-role choice. Code blends 0.45/0.25/0.30, discounts `generated` (0.08) and `test` (0.03), then applies the existing 70% decision / 30% vector policy. `decision_role` and a readable `rationale` are returned to agents.
3. **Routing** — `needs_retrieval`, five-way `target_domain`, and new `context_freshness` in one batch.
4. **Faithfulness** — noul + five-level score → `0.6*noul + 0.4*score/4`.
5. **Agent primitive** — `ainish-rag decide <state> --questions <json|@file>` returns typed answers with `model`, `source`, and `usage`; `--question` is a single-noul shortcut.
6. **Key resolution** — the decision engine now uses the shared provider resolver (`provider::resolve_named_secret` / `_pqc_export`), accepting consumer-prefixed store names; `secrets` reports the resolution source and model.
7. **Skill pack `.agents/skills/typesafe-jev/`** — SKILL.md, `references/{api-contract,rag-decision-catalog,agent-coherence,calibration-and-testing}.md`, and dependency-free `scripts/jev_probe.py`. Front matter passes `bin/security_gate.py`; deploys via `--rules`/`--skills`.
8. **Docs** — `llms.txt` decision section rewritten; `AGENTS.md` REFERENCE row for `ainish-rag decide` and the rerank/decision contract updated.
