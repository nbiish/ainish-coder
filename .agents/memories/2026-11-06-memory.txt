### [2026-11-06T14:30:00Z] rules-deploy-needed-a-signer-preflight
Deployment provenance is ML-DSA-65 signed, but the compiled engine is a gitignored build artifact, so a fresh clone has no signer. deploy_rules_sync wrote the manifest and refresher first and only then attempted signing, leaving clones with a manifest that could never verify, armed hooks, and no fleet enrollment - a half-deployed target behind a one-line warning. A signer preflight now runs before anything is written, so the refusal is clean and names the build step. The signature was deliberately NOT made optional: relaxing a fail-closed trust boundary to suit a missing build artifact would be the wrong fix.


### [2026-11-06T17:05:00Z] a-saturated-benchmark-is-not-a-baseline
The ainish-rag baseline recorded only binary Recall@3 on three synthetic queries, all passing, so it read 100% and could never show improvement. A metric everyone already scores perfectly is a ceiling, not a floor; adding nDCG and pinning the embedding identity is what made later retrieval work measurable. The same pass showed that normalizing DCG against a guessed ideal can produce nDCG above 1.0 (observed 2.131), so a metric needs a range assertion, not a spot check. Separately, bin/ainish-rag accepted a file named ainish-rag beside itself as its native binary and exec'd it, which is why shell launchers must compare resolved paths rather than names before handing off.

### [2026-11-06T18:45:00Z] wsl-exe-output-encoding-is-not-fixed
pwc-secrets decoded 'wsl.exe -l -q' output unconditionally as UTF-16-LE. On this Windows build wsl.exe emits UTF-8, so every distro name became mojibake, the \\\\wsl.localhost\\<distro> interop probe never matched, and Windows silently used a local store with 0 keys while 13 keys sat in the WSL store. Detection must come from the byte shape (UTF-16-LE ASCII is NUL-padded) rather than an assumption about the tool, and both the modern wsl.localhost share and the legacy wsl\$ share should be tried. A second lesson from the same pass: HOME= is not isolation on Windows because Python reads USERPROFILE and pathlib.Path.home() ignores HOME, so a supposedly hermetic test was reaching real key material; pin the program's own documented override instead.
