Contract files carry macOS `uchg` (user immutable) — `chflags nouchg` only on the task's own worktree copies, never the main checkout.
- aiRPC query calls (`kind: "query"`, empty path/block_id/digest) are answered in the ack and never edit; `validateAck` requires `new_digest` only when `block_id` is non-empty.
