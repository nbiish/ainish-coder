# Durable Memory — 2026-11-25 12:00 UTC

- **Hermes toolless one-shot invocation:** `hermes chat -t none` is rejected (`invalid_params: unknown or invalid toolset name: 'none'`) and `--no-restore-cwd` is rejected with `--format stream-json`. Use `--profile <name> chat --query-file - --oneshot -Q --source tool --format stream-json --max-turns 1` via stdin and configure `platform_toolsets:\n  cli: []` in the profile `config.yaml` (plus `memory_enabled: false` and `user_profile_enabled: false` for stateless `context-goldfish`).
- **Windows Git Bash / MSYS2 traps:**
  - `ln -sf .../python.exe /tmp/bin/python3` copies `python.exe` without `python312.dll` (exit 127); use a shell script wrapper (`exec /c/.../python.exe "$@"`) or native `py -3`.
  - `_ms_smoke_peer` must not invoke `cmd /c ...` for local Windows checkouts (`host == ""`) inside MSYS2 because `/c` is rewritten into a POSIX path and hangs `cmd.exe`.
  - `_ml_repo_key` stores MSYS2 POSIX paths (`/d/...`) whereas `git rev-parse --show-toplevel` returns `D:/...`; `_ms_linked_path` normalizes both.
  - Loops reading `links.txt` must pass `</dev/null` to `ssh`-based `_ms_probe_peer` or preload lines into an array so `ssh` never drains remaining file lines.
