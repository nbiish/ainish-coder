- "Mandatory" skill packs are one predicate (`_skill_mandatory` in `src/skills_selection.sh`). Every
  surface asks it: deploy, sync, verify, selector list, both toggle UIs, and the report. A second list
  that merely repeats the names — the old `_skill_channel_excluded` entry — is how a pack ends up
  mandatory in distribution and toggleable in the UI.
- A hidden list drifts silently. `_skills_mandatory_names` had been left at one name while the
  predicate carried two; derive such sets by enumerating the source through the predicate instead of
  re-typing them.
- Distribution verbs must agree. `--rules` shipped mandatory packs, `--skills-verify` failed them when
  absent, and `--skills-sync` skipped them: honouring a stale recorded `off` for a mandatory pack is
  the same bug class as hiding it from the selector.
- Refreshing the contract via the deploy path re-signs `.agents/canonical/*` and appends to
  `.agents/audit/contract-history.jsonl` with the local signer. That signer is not the committed
  trust anchor, so every refresh adds artifacts the anchor rotation must re-sign.

- "Newest wins" must mean newest by MTIME, never by filename. Under mixed naming `{date}-09-memory.md`
  sorts before `{date}-memory.txt` ('0' < 'm'), so a name-sorted pick returns the grandfather file as
  "newest" — silently, on exactly the cutover days it matters. Fixed in one shared resolver in
  `src/rag/rag.py` (`_coordination_files` + `_memory_files`/`_task_files`/`_plan_files`/`_comms_files`)
  and mirrored in the Rust crate; do not reintroduce a local glob with `[-1]` or `.last()`.
- `ainish-rag` on this host is the PYTHON engine: `bin/ainish-rag` forces `context`/`secrets` to
  `rag.py` and no `bin/ainish-rag-{darwin,linux}`/`.exe` exists, so `src/rag/target/release/ainish-rag`
  never answers a request. Change `rag.py` for behaviour, and mirror the crate so a native build does
  not regress. A plan that scopes engine work to the Rust crate alone is scoping the wrong file.
- Dropping a filename suffix turns every suffix filter into one that matches nothing, and matching
  nothing reads as "no plan of record" instead of an error: `*.plan.md` globs in `plan_gate.sh`,
  `rag.py`, and `context-packet.sh` would have blocked every new-scheme branch.
