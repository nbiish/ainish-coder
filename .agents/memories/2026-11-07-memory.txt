### [2026-11-07T02:55:00Z] a-fallback-order-belongs-to-its-consumer
The driver order lives in `ainish-rag` (`DRIVER_CHAIN`), not in local-router's `fallback-models` chain. That chain is shared with VS Code, Claude Code, Cline and every other client on the machine, so repointing it to suit one tool reroutes everything. ### [2026-11-07T03:20:00Z] hidden-from-the-prompt-is-not-always-shipped
A pack can be invisible to the operator and still mandatory, but only if the code keeps those two ideas on separate axes. Collapsing them was the bug: `pqc-secrets` was excluded from the selector (a prompt-surface decision) and therefore never deployed (a runtime dependency the contract resolves every secret through), so a repo could end up with a contract that assumed an engine it never received. The durable shape is two predicates — excluded-from-selection and mandatory — plus one shared list every path (deploy, verify, status, sync) consults, so a pack cannot be mandatory in one place and optional in another. Two follow-ons that only surface under load: a mandatory pack must MIRROR rather than merge, or a file deleted upstream survives and the deployed copy stops matching its signed digest; and because `deploy_path_contents` reads the no-overwrite flag from the environment, an outer exemption is not enough — the flag has to be bypassed at the copy layer too.

### [2026-11-07T03:20:00Z] one-wrong-url-looks-like-six-dead-vendors
Six direct providers all returned 404 on chat completions. The obvious reading was that six vendors had blocked or retired their endpoints. The actual cause was one bug: provider bases end inconsistently (`https://openrouter.ai/api/v1` versus Z.AI's `https://api.z.ai/api/coding/paas/v4`) and the client appended a fixed `/v1/chat/completions`, producing `/api/v1/v1/...` on every one of them. What made this expensive was that the reachability probe had the same hardcoded suffix, so the diagnostic agreed with the bug — six "down" entries were really six healthy hosts answering a malformed path. Two lessons: derive probe URLs from the same function that builds request URLs, or the probe becomes a confirmer instead of a check; and when many independent integrations fail identically, suspect the shared code path before the vendors. Related: treat "reachable" as "the host answered HTTP at all", not "it served the catalogue I expected" — several providers 404 `/v1/models` while serving chat normally, and calling that "down" is the same class of false negative.

### [2026-11-07T21:40:00Z] text-true-is-a-platform-bet
`subprocess.run(..., text=True)` decodes with the platform default, which is cp1252 on Windows and UTF-8 nearly everywhere else. Any tool that writes UTF-8 - which is every tool written on Linux or macOS - then crashes the caller on a Windows host, and the failure looks nothing like an encoding problem: it surfaces as a UnicodeDecodeError inside reader-thread cleanup while the process is already exiting, so the command dies with a traceback whose last frame is in threading internals. The trigger is narrow enough to hide for months: em-dashes and en-dashes decode to mojibake, but a character whose UTF-8 third byte is 0x90 (U+2010 HYPHEN, U+0110) is undefined in cp1252 and raises. Pass `encoding="utf-8"` and `errors="replace"` explicitly on any subprocess whose output you parse, and prefer bytes plus an explicit decode when the payload matters.

### [2026-11-07T23:05:00Z] the-spelling-in-the-contract-is-an-interface

### [2026-11-07T23:05:00Z] same-model-can-still-be-a-second-opinion
I had defaulted the reviewer to a different model on the reasoning that a same-model critic shares the drafter's blind spots. That is true, and it is not the only effect the pair relies on: a reviewer with no accumulated session state reading the same evidence catches things an incremental drafter missed, and that works on one model. Different models is the stronger version, not the definition. The correction was to make the specified behaviour the default and the stronger behaviour an explicit opt-in - and to fix the reporting, which had framed the default as a defect ("SAME MODEL, reviewer shares the drafter bias") instead of describing it ("same model, fresh context").
