- A chain step's NAME is not its TRANSPORT. Carrying `"transport": "local-router"` on a vendor-named
  step means the id is sent to the local router and the vendor is only reached if the router chooses
  it — so a router with one dead upstream fails several "different" steps at once. Pin the
  `(transport, id)` pairing in tests, never just the id list.
- The PQC vault is locked on this host: `_pqc_export()` returns 0 entries and `resolve_driver_key`
  returns None for every direct transport, so steps 2-4 skip with "no API key resolved". `pqc-secrets
  export --json` prompts for a passphrase when locked. Do not fake keys with env vars to "prove" a
  direct path — that proves nothing about the real one.
- `probe_health` treats a reachable `/models` as "up", but OpenRouter serves that catalogue publicly
  with no auth, so a step can report `up` while its chat path would 401. `up` means "endpoint
  answered", not "this step will work".
- When diagnosing a 401 from a provider, check whether the key RESOLVED before believing the error
  text: a manual request with `Bearer None` yields a plausible-looking "token expired/incorrect" from
  Z.AI and "Missing Authentication header" from OpenRouter, which points at keys when the real cause
  is the locked vault.
- The elephant and goldfish roles run as `pi` agents (2026-11-14), not in-process chat calls:
  `pi --print --no-session --no-tools --mode json --thinking <level> --model <id>
  --append-system-prompt <brief> @file...`. `--no-session` is what makes EGM's fresh-reader rule
  structural; `--no-tools` is what stops a context call from acquiring authority. pi's JSON stream
  carries typed blocks, so `thinking` must be filtered or it leaks scratch work into the prime.
- pi resolves model ids against ITS OWN provider catalog, where a bare `glm-5.3-flash` is ambiguous
  across five providers and pi refuses rather than guessing. Engine transports are translated to
  pi-qualified ids in `PI_MODEL_IDS` (`zai/glm-5.3-flash`, `xiaomi/mimo-v2.6-pro`,
  `openrouter/deepseek/deepseek-v4.1-flash-1017`).
- pi's cost is its agentic system prompt, not our payload: a one-word reply costs 6,904 input tokens
  at `--thinking high` and 56 at `off`. Thinking level is the lever; trimming our prompt is not.
- Hand a reviewer its input WHOLE. A 3,000-char slice truncated the elephant note mid-sentence and the
  reviewer spent a finding reporting that its own subject was incomplete.
- Attaching files beats inlining: with the full vault page attached the reviewer reasoned about
  provenance (a generated page postdates the code it summarises) rather than paraphrasing an excerpt.
