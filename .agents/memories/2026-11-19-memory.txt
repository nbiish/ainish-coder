15:20 UTC -- context-agent correctness (feat/context-agent-correctness)
- `ainish-coder --context "<input>"` is the documented entry point; `ainish-rag` forwards with a deprecation line. The envelope header says `ainish-coder context`.
- `BASE_PROFILE` graph caps are 0 (= index everything) and `base_settings()` derives from `BASE_PROFILE`; a duplicated literal there is what silently disabled the whole-corpus fix for a day.
- `.agents/context-harness/skills/` is the ONE learned-skill surface: the graph indexes it and `render_staged_skills` surfaces it from the same walk.
- Acceptance referent order: `--outcome` override > `.agents/tasks/*.md` at `status: done` > commit-subject overlap. `status: done` is accepted without landing corroboration because every historical record names a rebased-away sha; the generation reports `corroborated: false`.
- A generation is profile + `.skills` snapshot; `archive_live_generation` must run BEFORE staging or the snapshot captures the new tree.
- `resolve_canonical_repo_root` maps a worktree to the MAIN checkout — correct for caches, wrong for tracked learned state, hence `_learned_root` / `resolve_worktree_root`.
- `AINISH_BIN_DIR` (readonly, set before sourcing) exists because `src/deploy_commands.sh` reassigns `SCRIPT_DIR` to its own directory.
- Retrieval: `KIND_INTENT` boosts the layer a task names; a naming task forces retrieval past `skip_retrieval`; `GRAPH_MAX_EDGES_PER_NODE = 24` bounds vocabulary edges.
15:55 UTC -- RAG retirement (feat/retire-rag)
- One engine: `src/context/engine.py`. `bin/ainish-context` launches it; `bin/ainish-rag` is a shim that forwards and prints one deprecation line on stderr.
- The Rust crate is deleted. Nothing dispatches to a native binary; a missing Python interpreter is a hard error, never a silent fallback.
- Signing is ML-DSA-65 in Python via `cryptography` (uv `--with cryptography>=47` in the launcher, stdlib-only engine otherwise), seed from `AINISH_MLDSA65_SEED` or `.agents/audit/signer.mldsa65.priv`, and the canonical checkout is the fallback location for the seed (a worktree has none of its own).
- Envelope naming is `x.md` -> `x.sig` (suffix REPLACED, not appended). Appending writes `x.md.sig`, which no reader looks for.
- `audit verify` compares the envelope's `sha256` to the artefact. Checking that `.sig` EXISTS is a fail-open gate; it passed on a manifest rewritten after signing.
- Audit/lock/SBOM receipts use the WORKTREE root (`_learned_root`); caches use the canonical root.
- Retired verbs are not registered as subparsers: `_first_retired_verb` intercepts before argparse so the message explains the retirement instead of reading as a typo.
- `ainish-rag/<name>/vN` strings are on-disk SCHEMAS and must not be renamed with the tool.
