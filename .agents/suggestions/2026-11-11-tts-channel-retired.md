# TTS channel retired in favour of `.agents/suggestions/`

**Decision (operator, 2026-11-11):** stop using the `tts-cli` end-of-turn spoken-suggestion channel.
The durable-note surface is now `.agents/suggestions/` — one file per topic, written by whoever has
something the next session should know, read by `ainish-rag --context` as part of the newest-artifact
corpus.

**Removed:** `AGENTS-TTS-COMMS.txt` (564 lines) from the repository root, the `tts-cli` entry in
`src/help.sh`'s pack list, and the TTS row plus its tree entry in `README.md`.

**Not removed:** `skills-to-distribute/skills/tts-cli/` stays on disk. It is the operator's tool and
may be adopted again; it is simply no longer advertised or used as a standing end-of-turn step. Nothing
selects it, and optional packs default to off.

**Why the file had to go rather than be annotated:** it was 564 lines of standing prompt surface in the
repo root, generated by a channel that is no longer run. A transcript nobody appends to is context rot
with a maintenance cost. The history is preserved in git; the working tree no longer carries it.

**What replaces it, concretely:** anything worth carrying forward gets a dated file under
`.agents/suggestions/` (gaps, decisions, things to try next), or a task record under `.agents/tasks/`
once it is acted on. Both are already in the retrieval corpus, so a suggestion written today is context
an agent receives tomorrow without any extra plumbing.
