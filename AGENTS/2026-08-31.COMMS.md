# AGENT COMMS — 2026-08-31

<PROTOCOL>
## PROTOCOL (binding — follow like AGENTS.md)

**When:** ≥1 agent or subagent is working at once (multiple branches, features, updates, bugs, docs). Solo? Still check in/out — the ledger is the audit trail.

**Two channels:**
- **This file** (`AGENTS/{date}.COMMS.md`) — committed, append-only durable ledger. Updated via your task-branch commits; reaches everyone at merge.
- **Live board** (`AGENTS/{date}.COMMS.live.md`) — gitignored, at the **main repo path**. Append here by absolute path for immediate in-flight visibility. Never `git commit` it; never `git add` it. Main stays clean.

**Read:** this file + the live board — at start, before any merge, and whenever blocked.

**Write:** for every lifecycle event, append one entry block to **both** the live board (immediate) and this file in your worktree (durable — commit it). One writer per branch. Subagents do not write the shared files directly: report results to your orchestrator, who logs on your behalf with `parent:` set.

**Timestamps — mandatory, bracketed, ISO-8601 (UTC `Z` form on this ledger):**
- `start:` the instant the agent **begins** the action (input received / work begun).
- `end:` the instant the agent **finishes** it (output produced / work handed off or halted).
- **Every** entry has both. Abandoned mid-action → still close with `end:` + `status: abandoned`.

**Entry block:**

~~~
### [<ISO-8601 timestamp>] <EVENT> | agent:<name> | branch:<branch> | wt:<worktree-path>
- start:<ISO-8601>               # input received / work began
- end:<ISO-8601>                 # output produced / work ended
- parent:<orchestrator>          # subagents only
- scope:<paths/modules>
- objective:<one line>
- input:<one line — what was received or requested>
- output:<one line — what was produced or handed off>
- status:<new|in-progress|blocked|verifying|merged|abandoned>
- blockers:<none | description>
~~~
